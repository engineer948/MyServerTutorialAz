UNIT · FEDORA SERVER

Fedora Server necə qurulur?

Sıfırdan Fedora Server quraşdırılması və üzərində hazır gələn Cockpit veb panelindən istifadə edərək serverini brauzerdən idarə etmək — komandaları ilə birgə, addım-addım.

Çətinlik: Orta Təxmini vaxt: ~25 dəqiqə Lazımdır: köhnə kompüter/mini PC, min. 4GB USB
▶ Video Bələdçi — Fedora Server Quraşdırılması

1. Fedora Server quraşdırılması

ISO faylını yüklə

fedoraproject.org/server/download ünvanından Fedora Server ISO faylını (DVD ISO) kompüterinə yüklə.

Bootable USB hazırla

Rəsmi tövsiyə olunan Fedora Media Writer proqramı (və ya Rufus/balenaEtcher) ilə yüklədiyin ISO faylını ən azı 4GB-lıq USB flash karta yaz.

USB-dən başlat

USB-ni kompüterə tax, yenidən başlat və BIOS/UEFI menyusunda boot sırasını USB-yə yönləndir.

Anaconda quraşdırma sihirbazını izlə

Dil və klaviatura düzümünü seç. "Installation Destination" bölməsində diski seçib "Done" et — Fedora avtomatik olaraq LVM+XFS bölgüsü quracaq, yeni başlayanlar üçün bu kifayətdir. "Network & Host Name" addımında mümkünsə statik IP təyin et.

Software Selection-da "Headless Management"-i işarələ

Bu, dərslikdəki ən vacib addımdır: "Software Selection" bölməsində Headless Management qutusunu işarələ. Bu seçim Cockpit veb panelini avtomatik quraşdırır və aktivləşdirir — sonra əlavə heç nə etməyəcəksən.

İstifadəçi hesabı yarat

"User Creation" ekranında öz adın/şifrənlə hesab yarat və "Make this user administrator" qutusunu mütləq işarələ — bu, sudo hüququ verir.

Bitir və yenidən başlat

"Begin Installation" düyməsinə bas, quraşdırma tamamlandıqda USB-ni çıxar və kompüteri yenidən başlat.

Başqa kompüterdən SSH ilə qoşul

Fedora Server-də SSH standart olaraq aktivdir. Eyni şəbəkədəki başqa kompüterdən terminal aç:

terminal
ssh istifadeci_adin@server_ip_unvani

Sistemi yenilə

terminal
sudo dnf update -y
Cockpit

2. Cockpit necə istifadə olunur?

Cockpit — Fedora Server-in özündə hazır gələn, brauzerdən istifadə olunan idarəetmə panelidir. "Headless Management" seçilibsə, əlavə quraşdırmaya ehtiyac yoxdur — birbaşa istifadəyə hazırdır.

Brauzerdən aç

İstənilən kompüter/telefonun brauzerində https://server_ip_unvani:9090 ünvanını aç. Sertifikat xəbərdarlığı çıxa bilər (Cockpit özünütəsdiqləyən sertifikatdan istifadə edir) — "Advanced" → "Davam et" seçərək keç.

Sistem hesabınla daxil ol

Quraşdırma zamanı yaratdığın istifadəçi adı/şifrə ilə giriş et. Ayrıca hesab yaratmağa ehtiyac yoxdur.

Paneli tanı

Sol menyudan Overview (CPU/yaddaş/disk), Services, Terminal, Storage və Networking bölmələrinə baxa, serverini tamamilə brauzerdən idarə edə bilərsən.

Konteynerləri idarə et (Podman)

Cockpit-ə Docker-uyğun konteynerləri idarə etmək üçün Podman modulunu əlavə et:

terminal
sudo dnf install cockpit-podman -y

Brauzeri yenilə — sol menyuda "Podman containers" bölməsi görünəcək. Buradan Jellyfin, Nextcloud kimi tətbiqləri UI üzərindən işə sala bilərsən.

Qeyd: CasaOS rəsmi olaraq Fedora-nı dəstəkləmir (dnf paket uyğunsuzluqları quraşdırmanı tez-tez uğursuz edir), ona görə bu dərslikdə Fedora-nın öz hazır panelini — Cockpit-i istifadə etdik. Ubuntu Server və ya Raspberry Pi OS-da CasaOS istəyirsənsə, digər dərsliklərimizə bax.
