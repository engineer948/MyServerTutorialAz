UNIT · DEBIAN SERVER

Debian Server necə qurulur?

Sıfırdan stabil Debian Server quraşdırılması, sistem idarəetməsi üçün Cockpit paneli və ev serverini mükəmməl multimedia/bulud mərkəzinə çevirən CasaOS-in addım-addım qurulması.

Çətinlik: Orta Təxmini vaxt: ~35 dəqiqə Lazımdır: Mini PC / köhnə kompüter, min. 4GB USB
▶ Video Bələdçi — Debian Server + CasaOS Quraşdırılması

1. Debian Server quraşdırılması

ISO faylını yüklə

debian.org rəsmi saytından Debian "Netinst" (şəbəkə quraşdırıcısı) və ya tam DVD ISO faylını kompüterinə yüklə.

Bootable USB hazırla

Rufus, balenaEtcher və ya Ventoy proqramından istifadə edərək yüklədiyin Debian ISO faylını USB flash karta yazdır.

USB-dən başlat və Quraşdırıcını seç

USB-ni server edəcəyin kompüterə tax, başladarkən BIOS/UEFI menyusundan USB-ni seç. Açılan menyuda "Graphical Install" rejimini seç.

Dil, Şəbəkə və Şifrə tənzimləmələri

Dil və klaviatura düzümünü seç. Şəbəkə ayarlarından sonra sizdən root şifrəsi və əsas istifadəçi (user) hesabı yaratmaq tələb olunacaq. Hər iki şifrəni təhlükəsiz bir yerdə qeyd et.

Disk Bölgüsü (Partitioning)

Yeni başlayanlar üçün "Guided - use entire disk" seçimi idealdır. Diski seç və sistemin avtomatik olaraq kök (root) və swap bölmələrini yaratmasına icazə ver.

Software Selection (Vacib Addım!)

Proqram təminatı seçimi ekranında serverin yüngül və performanslı olması üçün masaüstü mühitlərinin (GNOME, XFCE və s.) işarəsini yığışdır. Yalnız "SSH server" və "standard system utilities" seçimlərini aktiv saxla.

GRUB Boot Loader-i quraşdır və bitir

Quraşdırmanın sonunda GRUB yükləyicisini əsas diskinə yazmağa icazə ver ("Yes"). Proses bitdikdən sonra USB-ni çıxar və sistemi yenidən başlat (Reboot).

Sistem Hazırlığı və SSH

2. İlk Ayarlar və SSH Qoşulması

Server qoşulduqdan sonra onu digər kompüterdən terminal vasitəsilə idarə edəcəyik.

SSH ilə serverə bağlan

Eyni şəbəkədə olan digər kompüterinizin terminalından serverə qoşulun:

terminal
ssh istifadeci_adin@server_ip_unvani

Sudo hüquqlarını aktivləşdir (Əgər aktiv deyilsə)

Debian-da yeni istifadəçini sudo qrupuna əlavə etmək üçün əvvəlcə root rejiminə keçib lazımi paketi quraşdırırıq:

terminal
su -
apt update && apt install sudo -y
usermod -aG sudo istifadeci_adin
exit

exit etdikdən sonra terminalı bağlayıb yenidən SSH ilə daxil olun ki, sudo hüquqları aktivləşsin.

Cockpit Paneli

3. Cockpit Veb Panelinin Quraşdırılması

Cockpit — serverin resurslarını (CPU, RAM, Disk, Şəbəkə) brauzerdən izləmək və idarə etmək üçün yüngül idarəetmə panelidir.

Cockpit-i sistemə yüklə

Aşağıdakı komanda ilə Debian repozitoriyasından rəsmi Cockpit paketini quraşdırın:

terminal
sudo apt install cockpit -y

Brauzerdən daxil ol

İstənilən brauzerdə https://server_ip_unvani:9090 ünvanına keçid edin. Təhlükəsizlik xəbərdarlığını ("Advanced" -> "Proceed") keçərək server istifadəçi adı və şifrənizlə daxil olun.

CasaOS İnteqrasiyası

4. CasaOS Quraşdırılması (Docker & App Store)

CasaOS — Debian üzərində işləyən, Docker konteynerlərini tək kliklə idarə etməyə imkan verən, Nextcloud, Plex, Jellyfin kimi tətbiqləri rahatca qurmağınızı təmin edən mükəmməl bir ev bulud interfeysidir.

CasaOS-i tək komanda ilə quraşdır

Rəsmi CasaOS quraşdırma skriptini işə salın. Bu skript avtomatik olaraq Docker mühitini və lazımi asılılıqları tənzimləyəcək:

terminal
curl -fsSL https://get.casaos.io | sudo bash

Quraşdırma bir neçə dəqiqə çəkə bilər. Bitdikdən sonra terminalda sizə giriş linki göstəriləcək.

CasaOS Dashboard-a daxil ol

Brauzerinizdə birbaşa http://server_ip_unvani (port yazmadan, standart port 80-dir) yazaraq daxil olun. İlk açılışda sizdən CasaOS üçün ana admin hesabı yaratmağınız istəniləcək.

App Store-dan tətbiqləri kəşf et

CasaOS daxilindəki "App Store" bölməsinə daxil olaraq Jellyfin, Pi-hole, Transmission və ya qovluq paylaşımı (Samba) xidmətlərini heç bir terminal komandası yazmadan, tək kliklə quraşdırıb istifadə edə bilərsiniz.

Məsləhət: Debian Serverinizdə həm Cockpit (Port: 9090) həm də CasaOS (Port: 80) eyni anda problemsiz işləyir. Cockpit-i sistem yeniləmələri və terminal işləri üçün, CasaOS-i isə Docker tətbiqləri və fayl meneceri kimi istifadə edərək güclü bir ev serveri (NAS) əldə edirsiniz.
