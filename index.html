Hansı məqsəd üçün hansı dağıtım?

Hər self-hosting layihəsinin öz uyğun əməliyyat sistemi var. Aşağıda ən çox rast gəlinən məqsədlər və bu saytda öyrətdiyimiz uyğun seçim göstərilib.

🏠Ev serveri / CasaOS ilə fayl-media idarəsi → Ubuntu Server
🆕Ən son paketlər, developer-dostu mühit → Fedora
🥧24/7 işləyən, az enerji sərf edən kiçik layihə → Raspberry Pi OS
🖥️Hazır veb idarəetmə paneli (Cockpit) istəyənlər → Fedora

Hələlik bu 3 seçimi öyrədirik. Növbəti dərslərdə (Proxmox, TrueNAS və s.) əlavə olunacaq.
