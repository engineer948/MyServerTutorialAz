UNIT · RASPBERRY PI OS

Raspberry Pi OS necə qurulur?

Raspberry Pi Imager ilə monitor və klaviaturaya ehtiyac olmadan (headless) quraşdırma və üzərinə CasaOS ilə vizual idarəetmə panelinin əlavə edilməsi — komandaları ilə birgə, addım-addım.

Çətinlik: Asan-Orta Təxmini vaxt: ~20 dəqiqə Lazımdır: Raspberry Pi (3 və yuxarı), min. 16GB microSD
▶ Video Bələdçi — Raspberry Pi OS Quraşdırılması

1. Raspberry Pi OS quraşdırılması

Raspberry Pi Imager-i yüklə

raspberrypi.com/software rəsmi ünvanından öz əməliyyat sisteminə uyğun Raspberry Pi Imager proqramını yüklə və qur.

microSD kartı kompüterə tax

USB kart oxuyucu vasitəsilə ən azı 16GB-lıq microSD kartı kompüterinə qoş.

Cihaz və OS seç

Imager-i aç: "CHOOSE DEVICE"-dan öz Raspberry Pi modelini, "CHOOSE OS"-dan isə Raspberry Pi OS Lite (64-bit)-i seç (ev serveri üçün ekransız "Lite" versiya tövsiyə olunur). "CHOOSE STORAGE"-dan microSD kartını seç.

Advanced seçimləri aç (ən vacib addım)

Yazmadan əvvəl sağ alt küncdəki dişli çarx ikonuna (və ya Ctrl+Shift+X) klikləyib "OS Customisation" pəncərəsini aç. Bu addım sayəsində Pi-yə heç vaxt monitor/klaviatura qoşmadan (headless) birbaşa şəbəkəyə qoşula bilərsən.

SSH-i aktivləşdir və istifadəçi yarat

Enable SSH qutusunu işarələ və "Use password authentication" seç, öz istifadəçi adın və şifrəni təyin et. İstəsən "Configure wireless LAN" bölməsindən WiFi adı/şifrəsini də əlavə et.

Qeyd: Bookworm versiyasından etibarən standart pi / raspberry hesabı artıq yoxdur — istifadəçi adı və şifrəni mütləq özün təyin etməlisən.

Yaz və gözlə

"Save" sonra "Yes" düyməsinə bas. Yazma və doğrulama prosesi kartın sürətindən asılı olaraq bir neçə dəqiqə çəkəcək — prosesi yarımçıq kəsmə.

SD kartı Pi-yə tax və işə sal

microSD kartı Raspberry Pi-yə keçir və gücü qoş. İlk açılış fayl sistemini genişləndirdiyi üçün 2-3 dəqiqə çəkə bilər — bu müddətdə səbirli ol.

Başqa kompüterdən SSH ilə qoşul

Eyni şəbəkədəki başqa kompüterdən terminal aç:

terminal
ssh istifadeci_adin@raspberrypi.local

.local ünvanı işləməsə, router panelindən Pi-nin IP ünvanını tapıb onunla qoşul.

Sistemi yenilə

terminal
sudo apt update && sudo apt full-upgrade -y
CasaOS

2. CasaOS necə qurulur?

CasaOS — serverini brauzerdən, kliklərlə idarə etməyə imkan verən açıq mənbəli, pulsuz idarəetmə panelidir. 32-bit və 64-bit ARM sistemlərini dəstəklədiyi üçün Raspberry Pi 3 və yuxarı bütün modellərdə rahat işləyir. Terminal komandaları əvəzinə "App Store" bölməsindən Jellyfin, Nextcloud, Pi-hole kimi tətbiqləri bir kliklə quraşdıra bilərsən.

Quraşdırma komandasını işə sal

SSH ilə Pi-yə qoşulduqdan sonra bu komandanı yaz:

terminal
curl -fsSL https://get.casaos.io | sudo bash

Gözlə və ünvanı qeyd et

Quraşdırma bir neçə dəqiqə çəkəcək. Bitdikdə terminalda Pi-nin veb ünvanı görünəcək (məsələn http://192.168.1.60).

Brauzerdən aç

Həmin ünvanı istənilən kompüter/telefonun brauzerində aç və ilk istifadəçi hesabını yarat.

Tətbiq quraşdır

CasaOS panelində "App Store" bölməsinə keç və istədiyin tətbiqi bir kliklə quraşdır. Hazırsan!

Qeyd: Pi 3 və ya Pi Zero kimi zəif modellərdə çoxlu tətbiqi eyni anda işə salmaq yavaşlığa səbəb ola bilər — rahat təcrübə üçün Pi 4 (4GB+) və ya Pi 5 tövsiyə olunur. CasaOS-u silmək istəsən: curl -fsSL https://get.casaos.io/uninstall.sh | sudo bash
