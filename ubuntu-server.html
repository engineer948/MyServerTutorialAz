UNIT · UBUNTU SERVER

Ubuntu Server necə qurulur?

Sıfırdan Ubuntu Server quraşdırılması və üzərinə CasaOS ilə vizual idarəetmə panelinin əlavə edilməsi — komandaları ilə birgə, addım-addım.

Çətinlik: Asan Təxmini vaxt: ~25 dəqiqə Lazımdır: köhnə kompüter/mini PC, min. 4GB USB
▶ Video Bələdçi — Ubuntu Server Quraşdırılması

1. Ubuntu Server quraşdırılması

ISO faylını yüklə

ubuntu.com/download/server ünvanından ən son Ubuntu Server LTS versiyasını kompüterinə yüklə.

Bootable USB hazırla

balenaEtcher və ya Rufus proqramı ilə yüklədiyin ISO faylını ən azı 4GB-lıq USB flash karta yaz.

USB-dən başlat

USB-ni kompüterə tax, yenidən başlat və BIOS/UEFI menyusunda boot sırasını USB-yə yönləndir.

Quraşdırma sihirbazını izlə

Dil və klaviatura düzümünü seç. Şəbəkə addımında mümkünsə statik IP təyin et — server üçün tövsiyə olunur. Disk bölgüsündə "use an entire disk" seçimi yeni başlayanlar üçün kifayətdir.

OpenSSH Server-i aktivləşdir

Quraşdırma zamanı çıxan seçimdə "Install OpenSSH server" qutusunu mütləq işarələ — bu, serverinə uzaqdan qoşulmaq üçün lazımdır.

Bitir və yenidən başlat

İstifadəçi adı/şifrəni təyin et, quraşdırmanı tamamla, USB-ni çıxar və kompüteri yenidən başlat.

Başqa kompüterdən SSH ilə qoşul

Eyni şəbəkədəki başqa kompüterdən terminal/PowerShell aç:

terminal
ssh istifadeci_adin@server_ip_unvani

Sistemi yenilə

terminal
sudo apt update && sudo apt upgrade -y
CasaOS

2. CasaOS necə qurulur?

CasaOS — serverini brauzerdən, kliklərlə idarə etməyə imkan verən açıq mənbəli, pulsuz idarəetmə panelidir. Terminal komandaları əvəzinə "App Store" bölməsindən Jellyfin, Nextcloud, Pi-hole kimi tətbiqləri bir kliklə quraşdıra bilərsən.

Quraşdırma komandasını işə sal

SSH ilə serverinə qoşulduqdan sonra bu komandanı yaz:

terminal
curl -fsSL https://get.casaos.io | sudo bash

Gözlə və ünvanı qeyd et

Quraşdırma bir neçə dəqiqə çəkəcək. Bitdikdə terminalda serverinin veb ünvanı görünəcək (məsələn http://192.168.1.50).

Brauzerdən aç

Həmin ünvanı istənilən kompüter/telefonun brauzerində aç və ilk istifadəçi hesabını yarat.

Tətbiq quraşdır

CasaOS panelində "App Store" bölməsinə keç və istədiyin tətbiqi bir kliklə quraşdır. Hazırsan!

Qeyd: CasaOS-u silmək istəsən: curl -fsSL https://get.casaos.io/uninstall.sh | sudo bash
